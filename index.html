01

회원 식별자 기반 알림 등록·발송 개편

기존에는 알림을 회원 정보와 연결하지 않고 등록할 수 있었습니다. 회원 기준으로 등록·발송하도록 Java·SQL과 PC·모바일 화면을 수정했습니다.

  • 로그인·휴대폰번호 등록 여부에 따라 알림 등록을 제어하고, 등록·삭제와 삭제 후 빈 목록을 처리했습니다.
  • 알림 저장 시 회원 식별자를 연결하고, 발송 대상 번호를 회원 정보에서 조회하도록 수정했습니다.

결과 회원 기준 등록·조회·삭제·발송을 구현하고 기존 메시지의 중복 발송 여부를 점검한 뒤 PC·모바일 운영에 반영했습니다.

Java · SQL · JSP · JavaScript · Vue.js

  • 브라우저 인쇄를 시험한 뒤 jsPDF·html2canvas로 PDF 출력 모듈을 구성하고 페이지 경계의 내용 잘림을 완화했습니다.
  • 템플릿의 JavaScript 중복 로드로 클릭 이벤트가 여러 번 등록되는 것을 확인해 수정했습니다.

결과 PDF 다운로드를 운영에 반영하고 클릭 한 번에 다운로드가 중복 실행되는 문제를 수정했습니다.

SQL 집계와 Java 목록 처리의 조회 중복 수정

이력 조회에서 같은 대상의 건수가 나뉘고 결과 목록이 반복 표시됐습니다. 조회 SQL과 여러 DB 결과를 합산하는 Java 서비스 로직을 수정했습니다.

  • 이름 컬럼의 NULL 여부로 집계가 나뉘는 원인을 확인하고 GROUP BY 기준을 고유 식별자로 변경했습니다.
  • 반복문에서는 건수만 합산하고 결과 목록은 반복이 끝난 뒤 addAll로 한 번 추가하도록 수정했습니다.

결과 집계 건수와 결과 목록이 중복 없이 표시되는 것을 확인했습니다.
