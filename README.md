# 웹 개발자 이력서

`index.html`을 브라우저에서 열면 이력서를 볼 수 있습니다. 이 페이지는 문안 원본에서 생성한 정적 파일입니다. 내용 변경은 작성 환경의 원본에 반영한 뒤 다시 생성합니다.

## PDF 저장

상단의 **PDF 저장**을 누르면 이력서 본문을 A4 이미지 기반 PDF로 다운로드합니다. 캡처는 브라우저에서 처리됩니다.

## GitHub Pages

공개할 내용을 확인한 뒤 이 폴더의 파일만 별도 저장소 루트에 올립니다. 저장소 Settings → Pages → Deploy from a branch에서 main과 /(root)를 선택하고 저장합니다.
